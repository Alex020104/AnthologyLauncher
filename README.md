# A.N.T.H.O.L.O.G.Y — единая библиотека аддонов

Эта ветка хранит единый каталог аддонов Anthology 2.1 для Launcher Next. Она не заменяет рабочую ветку исходников и не затрагивает установленную игру.

Структура:

- `library/<категория>/` — отдельные архивы аддонов, готовые для установки в `MO2\mods`;
- `addon-catalog.json` — имена, категории, размеры, SHA-256 и прямые GitHub URL;
- `excluded-addons.json` — аддоны, которые нельзя положить в обычный Git из-за ограничения размера;
- `source-paths.md` — готовые шаблоны GitHub и Яндекс.Диска для Releaser Next и Launcher Next.

Архивы в этой ветке являются хранилищем библиотеки. Подписанный `manifest.json` обновлений создаётся только Releaser Next с закрытым ключом разработчика.
