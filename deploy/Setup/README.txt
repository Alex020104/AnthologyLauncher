ОБЫЧНЫЙ SETUP ANTHOLOGY
=======================

Эта папка копируется в App\Setup рядом с AnthologyLauncher.Next.exe.

Поддерживаемая структура:

Setup\AnthologySetup.exe       рекомендуемое имя установщика
Setup\Setup.exe                также обнаруживается автоматически
Setup\AnthologySetup.msi       MSI тоже поддерживается
Setup\bin\...                  бинарные файлы для Setup
Setup\Payload\bin\...          альтернативный каталог полезной нагрузки

Лаунчер не предполагает неизвестные параметры командной строки. Он запускает
EXE/MSI с рабочей папкой Setup, поэтому установщик может использовать любые
относительные пути внутри неё. Настоящие бинарные файлы игры в Git не входят.
