A.N.T.H.O.L.O.G.Y COMMUNITY SERVER
==================================

Адрес сайта и API на этом компьютере:
http://127.0.0.1:5249/

Папки:
App       — сервер и сайт;
Data      — база SQLite, вложения, токен и резервные копии;
Tools     — установка службы, подключение клиентов и обслуживание.

Первый запуск:
1. Запустите Start-CommunityServer.cmd.
2. Откройте Open-CommunitySite.cmd.
3. Запустите Tools\Configure-LocalClients.ps1, чтобы подключить лаунчер и релизер.

Постоянный запуск:
Запустите Tools\Install-Service.ps1 от имени администратора. После этого сервер
будет запускаться вместе с Windows и не будет зависеть от лаунчера.
Если права администратора недоступны, запустите Tools\Install-StartupTask.ps1 —
сервер будет автоматически запускаться после входа в вашу учётную запись Windows.

Токен разработчика:
Data\Config\developer-token.txt
Не публикуйте этот файл и не передавайте его игрокам. Он нужен только релизеру,
панели разработчика сайта и доверенным членам команды.

Резервная копия:
Tools\Backup-CommunityServer.ps1
Архивы сохраняются в Data\Backups.

Внешний доступ пока намеренно не включён. Порт 5249 слушает только локальный ПК.
Для открытия игрокам потребуются HTTPS, домен и настройка роутера либо защищённого туннеля.
